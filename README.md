A make.fun bounty entry: one word describing my Wi-Fi.

**The word: Ghosting** — my Wi-Fi vanishes mid-call, mid-download,
mid-sentence. It doesn't buffer, it doesn't warn you. It ghosts you.

`main.py` (Python standard library only) writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written anywhere.
